# Club photos

Drop real Naija FC Columbus photos here using these exact file names (JPG). Until a file exists, the site shows a green pitch design in its place.

| File | Where it appears |
|---|---|
| `hero.jpg` | Home page hero (wide, landscape) |
| `matchday.jpg`, `training.jpg`, `community.jpg` | Home page "Latest Moments" cards (portrait) |
| `story.jpg` | About page, Our Story (portrait) |
| `community-hero.jpg` | Community page (portrait) |
| `gallery-photos.jpg`, `gallery-videos.jpg` | Gallery page cards |
| `video-featured.jpg` | Videos page, featured video thumbnail |
| `gallery/*.jpg` | Photos page. Each photo is listed in `PHOTOS` in `index.html` with its match, category, title and player name tags (matches are listed once in `MATCHES`) |
| `videos/video-1.jpg` … `videos/video-6.jpg` | Videos page thumbnails |

Tip: resize photos to about 2000px on the long side and compress them so the site stays fast.
